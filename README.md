# 🍽️ Recipe Information Explorer

A simple and interactive Recipe Information Explorer built using HTML, CSS, and Python. The application fetches real-time recipe data from TheMealDB API and displays recipe details in a user-friendly interface.


## ✨ Features

- Fetches recipe data from TheMealDB API
- Displays recipe name and image
- Provides cooking instructions
- Interactive recipe selection buttons
- Responsive and visually appealing user interface
- API integration using JavaScript Fetch API
- Python script for API data retrieval

## 🍕 Available Recipes

- Pizza
- Burger
- Noodles
- Tacos
- Pancakes

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Click any recipe button to view recipe details.
